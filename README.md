# R4 Marine Science

## About

This repository contains my work for the R4 Marine Science programming module.  
It documents my development in R programming, data wrangling, data visualisation, reproducible workflows, Git/GitHub, and AI-assisted coding for marine science applications.

The repository is organised into four modules, with each module containing workshop exercises, analyses, code, and rendered outputs.

---

## Repository Structure

### Module 01 – Programming Foundations
Introduction to R programming and reproducible scientific workflows.

Topics include:
- R and RStudio
- Objects and variables
- Vectors and data frames
- Importing data
- Basic data manipulation
- R Markdown

### Module 02 – Data Wrangling and Visualisation
Using the `tidyverse` and `ggplot2` to manipulate and visualise scientific data.

Topics include:
- `filter()`
- `select()`
- `mutate()`
- `group_by()`
- `summarise()`
- `pivot_longer()`
- `pivot_wider()`
- Data visualisation with `ggplot2`

### Module 03 – Git and GitHub
Introduction to version control and reproducible research using Git and GitHub.

Topics include:
- Git repositories
- Commits
- Push and pull
- Repository organisation
- README documentation
- Version control for scientific workflows

### Module 04 – AI-Assisted Data Analysis
Exploring how generative AI can support programming and marine science data analysis.

Applications include:
- Code generation
- Debugging
- Code explanation
- Data exploration
- Visualisation development
- Scientific interpretation
